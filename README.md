# pgh-signage

The screens on the two TVs inside Paul's Guitar Hideout, Glens Falls, NY.

Each TV opens this site full screen. `live.json` names the set that plays (`sets/<name>.json`); change it and push, and both TVs switch on their next loop.

Textures are CC0 (Poly Haven, ambientCG); code credits are in `assets/tex/CREDITS.md`.
